# 앱인토스 검토 반려 사유 모음

새 반려가 오면 여기에 추가하고, 고친 코드에는 소스를 읽는 회귀 테스트를 하나 남긴다.

| # | 반려 문구(요지) | 원인 | 고친 방법 | 회귀 테스트 |
|---|---|---|---|---|
| 1 | 최초 화면에서 내비게이션 바 뒤로가기 클릭 시 미니앱이 종료되지 않아요 | 뒤로가기 구독 함수가 no-op 이었다 | `graniteEvent.addEventListener('backEvent')` 구독, 첫 화면이면 `closeView()` | toss.ts 에 backEvent 구독·closeView 호출, App 의 home 분기에 closeAppView |
| 2 | 내비게이션 바 뒤로가기와 미니앱 자체 헤더·뒤로가기 버튼이 함께 노출돼요 | 레이아웃이 ‹ 버튼과 화면 제목 헤더를 그렸다 | 자체 헤더 제거, 위 Safe Area 여백만 | AppLayout 소스에 `onClick={onBack}`·`aria-label="뒤로"` 없음 |

## 반려 전 실기기 지적으로 미리 고친 것

| 지적 | 고친 방법 |
|---|---|
| 광고가 예고 없이 뜬다 | 고르는 화면 제목 밑 `[광고]` 안내 박스 + 로딩 마지막 멘트 + 1.2초 틈 |
| 공유 글이 설명문 + "너는 몇 점인지 봐봐" | 결과 한 줄 + "나도 보러가기" + 딥링크 |
| 시각 모름을 골라도 "여덟 글자" 로 표기 | 실제 데이터 개수에 맞춰 문구 분기 |
| 저장된 정보 때문에 다른 사람 걸 못 본다 | 시작 시 "저장된 정보로 볼까요 / 새로 입력" 바텀시트 |
| 알림동의문 발송 시점에 시각 없음 → 캠페인 검수 탈락 | "매일 오전 10시, …" |
